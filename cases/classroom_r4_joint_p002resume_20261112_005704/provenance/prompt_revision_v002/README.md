# Prompt v002：完整补全灰色未知区域

本次仅修改提示词，尚未启动新推理。`prompt.txt` 是拟用于后续运行的完整英文 prompt；已执行 attempt 的实际提示词与结果保持原样。

主要修改：

1. 将“填满每一处灰色未知区域、形成完整场景视频”设为首要目标，置于 summary 和详细描述开头。
2. 明确灰色为未知占位数据，不是真实墙面/地面，也不属于应保留的画面内容；保留要求仅作用于非灰色的已观测场景。
3. 明确左侧补连续后墙、上部补天花板、下部补地面及有相邻布局支持的家具部分，同时要求纹理、光影、遮挡和跨帧稳定。
4. 要求从灰区首次出现到最终帧均完整填充，覆盖边缘和角落，消除切割轮廓；单纯换色或留下无细节平面不满足要求。
5. 保留原来的固定光心左转30°、窗户向右移动、proxy控制运动布局、参考图提供外观的约定。

本文件只记录文字修订，不代表模型执行了补全或结果通过视觉验收。模型配置、proxy、参考图均未修改。
